# EventEase AI – Smart Event Planner

EventEase AI is a GenAI-powered event planning application designed to make planning weddings, birthdays, and other celebrations easier.

## Features

* AI-powered event planning
* Budget planning
* Personalized event ideas
* Event preparation timeline
* Vendor checklist

## Technologies Used

* Google AI Studio
* Gemini AI
* React
* TypeScript

## Live Demo

https://eventease-ai-smart-event-planner.ai.studio

This project was developed for Hack2Skill Virtual PromptWars – Challenge 5: Celebration & Event Planner.
